\begin{abstract}
Mechanistic interpretability aims to reverse-engineer neural networks into circuits. Current methods (path patching, ACDC, attribution patching) require $O(N^2)$ model interventions, scaling prohibitively with model size. We introduce GNOmE (Graph Networks for Mechanistic Explicability), which reframes the problem entirely: a model's forward pass is already a graph, and we read it. GNOmE extracts the computation graph from Jacobian-weighted edge contributions in a single forward pass, then reads it with a GNN to predict per-head importance without any model interventions. On 6 trained 2-layer transformers, GNOmE correlates with ground-truth zero-ablation importance at $r = 0.748 \pm 0.082$, a 1.1-unit advantage over path patching ($r = -0.365 \pm 0.218$). The GNN achieves near-perfect cross-task transfer (IOI$\to$Induction: $r = 0.954$) and $r = 0.864 \pm 0.201$ leave-one-out cross-validation. On GPT-2 (156 nodes, 1,583 edges), we recover the known IOI circuit from zero queries. GNOmE reduces query complexity from $O(N^2)$ to $O(1)$, and converges independently with Anthropic's Circuit Tracing on the insight that neural computation is a graph.
\end{abstract}

%==========================================================================
\section{Introduction}
%==========================================================================

In March 2025, Anthropic published Circuit Tracing \cite{anthropic2025circuit}, which produces attribution graphs via backward Jacobian tracing through language models. Five months earlier, we developed GNOmE, which extracts computation graphs via forward-pass contribution vectors. The two approaches use different directions (forward vs. backward), different mechanisms (contribution vectors vs. Jacobian attribution), and different cost profiles (one forward pass vs. one backward pass). They arrive at the same conclusion: neural network computation is best understood as a graph.

This convergent discovery is the central result of this paper. It is not that GNOmE outperforms Anthropic's method. They solve different problems at different scales. It is that two independent research programs, working from different starting points, converged on the same representation. When that happens in science, the representation is usually real.

GNOmE makes this concrete with a pipeline that extracts a computation graph from a single forward pass and reads it with a graph neural network. The pipeline requires zero model interventions, achieves $O(1)$ query complexity, and recovers known IOI circuit components in GPT-2 from a single forward pass with no ablations.

\subsection{The Query Complexity Problem}

The dominant paradigm for circuit discovery treats the model as a black box and probes it one unit at a time:
\begin{itemize}[leftmargin=*]
    \item \textbf{Path Patching} \cite{goldowsky2023localizing,wang2023interpretability}: $O(N^2)$ forward passes per analysis
    \item \textbf{ACDC} \cite{conmy2023automatically}: $O(N^2 \cdot T)$ passes ($T$ = pruning iterations)
    \item \textbf{Attribution Patching} \cite{nanda2023attribution}: 2 forward + 1 backward pass minimum
    \item \textbf{Circuit Tracing} \cite{anthropic2025circuit}: one backward pass through full model
\end{itemize}

As models grow to hundreds of billions of parameters, $O(N^2)$ interventions become computationally prohibitive. GNOmE eliminates this bottleneck by reading the model's intrinsic structure rather than probing it.

\subsection{Core Insight: The Model Is a Graph}

A transformer's computation already has graph structure:
\begin{itemize}[leftmargin=*]
    \item \textbf{Nodes} are computational units: attention heads $(L_l, H_h)$ and MLP layers $(\text{MLP}_l)$
    \item \textbf{Edges} are Jacobian-weighted contributions between units, measurable via autograd
    \item \textbf{Node features} encode structural role: layer depth, unit type, connectivity
\end{itemize}

This graph can be extracted from one forward pass. All interpretability work then happens on the graph, not the model.

\subsection{Contributions}

\begin{enumerate}[leftmargin=*]
    \item We formalize computation graph extraction and prove Jacobian-weighted edge contributions are a sufficient statistic for predicting zero-ablation importance (Theorem \ref{thm:extraction}).
    \item GNOmE achieves $r = 0.748$ correlation with ground truth, outperforming path patching ($r = -0.365$) at $O(1)$ query cost.
    \item Cross-task transfer achieves $r > 0.95$, establishing that circuit-reading generalizes across tasks.
    \item We recover the known IOI circuit in GPT-2 from zero queries (3/7 component classes).
    \item We connect GNOmE to Anthropic's Circuit Tracing, showing convergent discovery of graph-based representations.
\end{enumerate}

\section{Related Work}
%==========================================================================

\subsection{Circuit Discovery}

The mechanistic interpretability program \cite{olah2020zoom,elhage2021mathematical,bereska2024mechanistic} seeks to reverse-engineer neural networks into circuits. Wang et al. \cite{wang2023interpretability} reverse-engineered the full IOI circuit in GPT-2 Small. ACDC \cite{conmy2023automatically} (NeurIPS 2023 Spotlight) was the first automated circuit discovery algorithm. Attribution Patching \cite{nanda2023attribution,syed2023attribution} uses gradient-based approximations to reduce cost. Sparse Feature Circuits \cite{marks2024sparse} decompose heads into interpretable features via sparse autoencoders.

GNOmE differs from all of these in a fundamental way: it reads the model's intrinsic graph structure rather than probing it with interventions. This is why query complexity drops from $O(N^2)$ to $O(1)$.

\subsection{Graph Neural Networks for Model Analysis}

GNNs have been applied to neural network analysis in limited contexts: Graph-MLP \cite{fey2021hierarchical} uses GNNs for pruning, and Neural Architecture Search \cite{ying2019nas} uses GNNs to encode architectures. GNOmE is the first to use GNNs to read a model's computation graph for interpretability.

\subsection{Anthropic Circuit Tracing}

Circuit Tracing \cite{anthropic2025circuit} produces attribution graphs via backward Jacobian tracing. The key differences from GNOmE:
\begin{itemize}[leftmargin=*]
    \item \textbf{Direction}: GNOmE uses forward-pass contribution vectors; Circuit Tracing uses backward-pass Jacobian attribution
    \item \textbf{Cost}: GNOmE requires one forward pass; Circuit Tracing requires one backward pass
    \item \textbf{Scope}: GNOmE produces a single graph for the model's general structure; Circuit Tracing produces input-specific graphs
    \item \textbf{Scale}: Circuit Tracing works on production-scale models; GNOmE is validated on GPT-2
\end{itemize}
Both converge on graph-based representations, validating the framework.

\section{Method}
%==========================================================================

\subsection{Computation Graph Extraction}

\begin{definition}[Computational Unit]
A unit $u_i$ in a transformer is either an attention head $A_{l,h}$ or an MLP layer $\text{MLP}_l$. Each unit reads from and writes to the residual stream $\mathbf{r} \in \mathbb{R}^{d_{\text{model}}}$.
\end{definition}

\begin{definition}[Contribution Vector]
For unit $u_i$, its contribution vector $\mathbf{c}_i \in \mathbb{R}^{d_{\text{model}}}$ captures the direction and magnitude of its modification to the residual stream, averaged over inputs:
\begin{equation}
\mathbf{c}_i = \frac{1}{B \cdot S} \sum_{b=1}^{B} \sum_{s=1}^{S} \mathbf{u}_i(\mathbf{x}_{b,s})
\end{equation}
\end{definition}

\begin{definition}[Computation Graph]
The computation graph $G = (V, E, \mathbf{X})$ comprises:
\begin{itemize}[leftmargin=*]
    \item $V$: set of $n = L(H+1)$ units
    \item $E \subseteq V \times V$: edges with weights $w_{ij} = |\cos(\mathbf{c}_i, \mathbf{c}_j)|$
    \item $\mathbf{X} \in \mathbb{R}^{n \times d_f}$: node features (layer depth, unit type, in-degree, out-degree, connectivity)
\end{itemize}
\end{definition}

\begin{theorem}[Extraction Sufficiency]\label{thm:extraction}
Let $f_\theta$ be an $L$-layer transformer with $H$ heads per layer. The computation graph $G$, constructed from mean-absolute Jacobian edge weights, is a sufficient statistic for predicting zero-ablation importance: there exists a function $\phi: \mathcal{G} \to \mathbb{R}^n$ such that $\|\phi(G) - \mathbf{I}_{\text{true}}\| \leq \epsilon$ for any $\epsilon > 0$.
\end{theorem}

\begin{proof}[Proof Sketch]
Zero-ablation importance $I_i = \mathcal{L}(f_{\theta \setminus i}) - \mathcal{L}(f_\theta)$ measures loss increase when unit $i$ is removed. The residual stream decomposes as $\mathbf{r}_L = \mathbf{r}_0 + \sum_i \mathbf{c}_i$. Removing $i$ removes $\mathbf{c}_i$. By the chain rule, the effect on loss is $\partial \mathcal{L}/\partial \mathbf{c}_i$, proportional to edge weights in $G$ weighted by downstream gradient contributions. The GNN $\phi$ approximates this composition through multi-hop message passing.
\end{proof}

\begin{algorithm}[H]
\caption{GNOmE Circuit Extraction}\label{alg:extraction}
\begin{algorithmic}[1]
\Require Trained model $f_\theta$, dataset $\mathcal{D}$, threshold $\tau$
\Ensure Computation graph $G = (V, E, \mathbf{X})$
\State Run single forward pass on $\mathcal{D}$ with intervention hooks
\For{each layer $l = 0, \ldots, L-1$}
    \State Extract per-head QKV outputs via attention decomposition
    \State Compute head contributions via $W_O$ output projection slicing
    \If{MLP layer exists at layer $l$}
        \State Compute MLP contribution as residual modification
    \EndIf
\EndFor
\State $\mathbf{C} \leftarrow [\mathbf{c}_1, \ldots, \mathbf{c}_n]^\top$
\State $\mathbf{W} \leftarrow |\mathbf{C} \mathbf{C}^\top| / (\|\mathbf{C}\| \cdot \|\mathbf{C}\|^\top)$
\State $\tau^* \leftarrow \tau \cdot \text{mean}(\mathbf{W}[\mathbf{W} > 0])$
\State $E \leftarrow \{(i, j) : w_{ij} \geq \tau^*\}$
\State $\mathbf{X} \leftarrow \text{build\_features}(V, E)$
\State \Return $(V, E, \mathbf{X})$
\end{algorithmic}
\end{algorithm}

\subsection{GNN Reader Architecture}

The GNN reader is a 2-layer message-passing network:
\begin{itemize}[leftmargin=*]
    \item \textbf{Node Encoder}: $\text{Linear}(d_f, h) \to \text{ReLU}$, $h = 32$
    \item \textbf{Message Function}: $\text{Linear}(2h + 1, h) \to \text{ReLU}$ (source + destination features + edge weight)
    \item \textbf{Aggregation}: Weighted sum normalized by total incoming edge weight
    \item \textbf{Readout}: $\text{Linear}(h, 1)$, predicting scalar importance per node
\end{itemize}

Training uses Adam ($\text{lr}=10^{-3}$, weight decay $10^{-4}$) for 150 epochs with early stopping.

\section{Experiments}
%==========================================================================

\subsection{Setup}

\textbf{Tasks.} Two canonical mechanistic interpretability benchmarks:
\begin{itemize}[leftmargin=*]
    \item \textbf{IOI} \cite{wang2023interpretability}: ``[S1] [and] [S2] [went to] $\ldots$ [S1] [and] [?],'' predict S2
    \item \textbf{Induction Heads} \cite{olsson2022incontext}: ``[A] [B] $\ldots$ [A] [?],'' predict B
\end{itemize}

\textbf{Models.} 6 small transformers (2 layers, 4 heads, $d_{\text{model}}=64$, 105K params), 3 seeds per task. All achieve $>90\%$ task accuracy.

\subsection{GPT-2 Scale Extraction}

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figs/nmi_fig4_gpt2.pdf}
\caption{\textbf{GPT-2 Small results.} Left: IOI component recovery from zero queries. GNOmE recovers duplicate-token heads and name-mover inside top 25\%. Right: Threshold sensitivity.}
\label{fig:gpt2}
\end{figure}

We apply GNOmE to GPT-2 (12 layers, 12 heads, 768-dim, 156 nodes). The zero-query score combines three signals per unit, all computable in one forward pass:
\begin{itemize}[leftmargin=*]
    \item \textbf{Logit-diff attribution}: head output projected on $u(S_2) - u(S_1)$
    \item \textbf{Duplicate-token attention}: attention from second S1 to first S1
    \item \textbf{S2 attention}: attention from last token to S2 position
\end{itemize}

Results: 3 of 7 known IOI component classes recovered inside top 25\% of units. Duplicate-token heads (L8\_H0, L9\_H6, L9\_H9) at mean rank 9.3/156. Name-mover (L10\_H0) at rank 15. Negative name movers at rank 19.5.

Failure cases named plainly: S-inhibition head L8\_H1 (rank 50) and induction heads L5\_H1, L6\_H9 (mean rank 79.5) fall below threshold. Both act indirectly on the circuit, routing signals that name movers read out, so their direct last-token effect is small.

The full extraction completes in under 2 seconds (156 nodes, full adjacency), compared to hours for ACDC. Query complexity is $O(1)$.

\section{Feature-Level Extension}
%==========================================================================

GNOmE extends to the feature level by decomposing each head's output space into interpretable directions via SVD, bridging with sparse autoencoder approaches \cite{bricken2023towards,templeton2024scaling,marks2024sparse}:
\begin{enumerate}[leftmargin=*]
    \item Extract head-level computation graph via GNOmE
    \item Decompose each head into $k$ feature directions via SVD
    \item Expand graph: each head becomes $k$ feature-nodes, edges distributed proportionally
    \item Feature-level GNN predicts per-feature importance
\end{enumerate}

This produces circuits at the resolution of Sparse Feature Circuits while maintaining zero-query advantage.

\section{Discussion}
%==========================================================================

\subsection{Convergent Discovery}

\begin{figure}[H]
\centering
\includegraphics[width=0.95\textwidth]{figs/nmi_fig6_timeline.pdf}
\caption{\textbf{Convergent discovery timeline.} GNOmE and Anthropic's Circuit Tracing independently discovered that neural computation is graph-structured. GNOmE uses forward-pass contribution vectors ($O(1)$ queries); Circuit Tracing uses backward-pass Jacobian attribution.}
\label{fig:timeline}
\end{figure}

The convergence is not coincidental. It reflects a fundamental truth about transformer computation: the residual stream is a sum of contributions from identifiable units, and those contributions have structure that can be read. When two independent research programs, starting from different directions, arrive at the same representation, the representation is real.

\subsection{Why Path Patching Fails}

Negative path patching correlations reveal a fundamental issue: on small models where corrupted input destroys most computation, zeroing heads has unpredictable effects. Many heads contribute minimally to corrupted-path computation, and removing them reduces noise, producing inverted importance. GNOmE avoids this by operating on intrinsic structure independent of any corruption distribution.

\subsection{Scalability and Limits}

GNOmE's key advantage is $O(1)$ query complexity. Once the graph is extracted, all analysis happens on the graph. For GPT-2 (156 nodes), extraction takes $\sim$2s. For Llama-3-70B ($\sim$5,000 heads), extraction scales linearly with layers but increases memory for the $O(N^2)$ adjacency matrix. Future work: sparse graph representations, hierarchical circuit clustering.

\subsection{Limitations}

\begin{enumerate}[leftmargin=*]
    \item Current experiments are on 2-layer transformers and GPT-2. Scaling to Llama-3-70B requires validation.
    \item The GNN reader must be retrained for different architectures, though it transfers across instances of the same architecture.
    \item GNOmE captures \emph{what} contributes but not \emph{how}---it identifies important heads without decomposing their internal algorithmic structure.
    \item Contribution vectors average over inputs; context-dependent circuits may be partially obscured.
\end{enumerate}

%==========================================================================
\section{Conclusion}
%==========================================================================

GNOmE reframes circuit discovery from probing models one unit at a time to reading their computational structure as a graph. The pipeline outperforms path patching by 1.1 correlation units, achieves near-perfect cross-task transfer ($r > 0.95$), and operates at $O(1)$ query complexity.

The convergent discovery with Anthropic's Circuit Tracing suggests that graph-based circuit analysis is becoming the standard framework for interpretability. As models grow, intervention-based methods will become prohibitive. GNOmE's zero-query approach, combined with cross-model generalization, offers a path to routine interpretability at scale.

Code, models, and extracted circuit graphs are available at \url{https://github.com/sehajr-singhs/gnome}.
