\begin{abstract}
Every method for finding circuits inside language models interrogates the model one component at a time. Path patching and ACDC require $O(N^2)$ interventions; attribution patching reduces this to $O(N)$ but still requires one gradient pass per component. We present \textbf{GNOmE} (Graph Networks for Mechanistic Explicability), a method that discovers neural circuits in a single forward pass with zero model interventions. GNOmE extracts the computation graph via blockwise Jacobian attribution, then reads the graph with a graph neural network (GNN) to predict per-component importance scores. On six synthetic transformers solving IOI-like tasks, GNOmE correlates at $r = 0.748$ with ground-truth zero-ablation importance, exceeding attribution patching ($r = 0.558$) and ACDC ($r = 0.505$). On GPT-2 Small (144 components), GNOmE achieves Spearman $r = 0.558$ and Pearson $r = 0.666$ rank correlation with ground truth, while attribution patching achieves $r = -0.017$ (essentially uncorrelated). GNOmE recovers 3 of 7 known IOI component classes from zero interventions, improving to 5/7 with the routing feature, compared to 2/7 for attribution patching. On a 12-layer transformer, GNOmE achieves $r = 0.987$ rank correlation with $10{,}588\times$ speedup over path patching. We demonstrate scaling to a billion-parameter model (Qwen2.5-1.5B, 1,544M parameters) with 1,790$\times$ memory reduction via sparse matrix storage. We find that GNOmE and Anthropic's Circuit Tracing~\cite{anthropic2025} independently converged on the same structural conclusion---neural computation is a graph---from different methodological directions, suggesting this is a fundamental property of transformer computation rather than an artifact of any single analysis method.
\end{abstract}

\section{Introduction}

The dominant paradigm in mechanistic interpretability is \emph{iterative interrogation}: ablate a component, measure the effect, repeat. Path patching~\cite{wang2023} corrupts a component's input and measures the causal effect on output. ACDC~\cite{conmy2023} sweeps through the full adjacency matrix, testing each edge. Attribution patching~\cite{syed2023} approximates the same sweep with gradient-based proxies. The cost scales as $O(N^2)$ for path patching and $O(N)$ for attribution patching, where $N$ is the number of components---attention heads, MLP layers, and embeddings.

In March 2025, Anthropic published Circuit Tracing~\cite{anthropic2025}, which extracts computation graphs from language models using activation pattern analysis and backward-Jacobian tracing. Their method reveals that neural networks have interpretable computational graphs that can be extracted, visualized, and analyzed as networks. This was a convergence: two independent lines of work arrived at the conclusion that neural computation \emph{is} a graph.

We ask: \emph{can a graph neural network read a model's computation graph directly and predict which components matter, without any interventions on the model?}

GNOmE is our answer. Given a trained model, GNOmE (1)~extracts its computation graph via blockwise Jacobian attribution in a single forward pass, and (2)~reads the graph with a trained GNN to score node importance. No iterative ablation. No corrupted inputs. No model interventions. $O(1)$ query cost.

The key contributions are:
\begin{enumerate}[nosep]
    \item \textbf{Zero-intervention circuit discovery}: GNOmE extracts circuits without modifying the model, achieving $r = 0.748$ correlation with ground-truth zero-ablation on synthetic models.
    \item \textbf{Attribution patching comparison}: We provide the first systematic comparison of GNOmE against attribution patching on GPT-2 IOI, showing GNOmE achieves $r = 0.558$ correlation where attribution patching achieves $r = -0.017$, with $443\times$ less computation.
    \item \textbf{Cross-task generalization}: A GNN trained on IOI circuits transfers to induction head detection ($r = 0.954$) without retraining, a capability unique to graph-based methods.
    \item \textbf{Billion-parameter scaling}: Sparse matrix storage and chunked computation enable GNOmE on models with 1,500+ components (Qwen2.5-1.5B), achieving 1,790$\times$ memory reduction.
    \item \textbf{Convergent discovery}: GNOmE and Anthropic's Circuit Tracing independently arrive at graph-based analysis of neural computation through different methodological paths, suggesting this reflects genuine computational structure.
\end{enumerate}

\section{Background and related work}

\subsection{Circuit discovery methods}

Circuit analysis~\cite{cammarata2020,elhage2021} established that neural networks compute through circuits of attention heads and MLP layers. The IOI paper~\cite{wang2023} demonstrated that specific attention heads implement specific computational roles---duplicate detection, name copying, inhibition---verifiable through causal interventions.

Path patching~\cite{vig2020,geiger2021} formalized the causal intervention: to determine whether component $j$ affects component $i$'s output, corrupt $j$'s input and measure the effect. This produces a causal adjacency matrix at $O(N^2)$ cost.

ACDC~\cite{conmy2023} automated the sweep by testing each edge using activation patching. Attribution patching~\cite{syed2023} approximates the same information with a cheaper gradient-based proxy---one forward and backward pass per component---reducing the constant factor but not the asymptotic scaling.

Sparse feature circuits~\cite{marks2024} extended circuit analysis to features decomposed via sparse autoencoders. Scaling monosemanticity~\cite{templeton2024} showed this scales to larger models.

\subsection{Graph-based analysis}

Anthropic's Circuit Tracing~\cite{anthropic2025} extracts attribution graphs via backward-Jacobian tracing. Their method produces human-readable graphs that reveal information flow through transformer layers. The result is a graph that humans can inspect, one graph at a time.

Micheli and Fleuret~\cite{micheli2023} showed that transformers can be viewed as graph neural networks, establishing a formal equivalence between the two architectures. GNOmE leverages this equivalence in reverse: by reading the transformer's computation as a graph, a GNN can predict which parts of the computation matter.

\subsection{Gap addressed}

Existing methods either require $O(N^2)$ model interventions (path patching), $O(N)$ gradient computations (attribution patching), or produce human-readable graphs without learned interpretation (Circuit Tracing). GNOmE is the first method that requires $O(1)$ queries, produces machine-readable importance scores, and generalizes across tasks without retraining.

\section{Method}

\subsection{Computation graph extraction}

Every neural network is a composition of differentiable blocks. A transformer has attention blocks and MLP blocks, each mapping activations from one layer to the next. GNOmE differentiates each block and reads the mean-absolute Jacobian as the edge weight between consecutive unit layers:

\begin{equation}\label{eq:jacobian}
    W_k[i,j] = \mathbb{E}_x \left| \frac{\partial u_{k+1}[i]}{\partial u_k[j]} \right|
\end{equation}

where $u_k$ is the activation vector of unit layer $k$, and the expectation is over a set of clean input examples. The Jacobian $W_k[i,j]$ measures how much unit $i$ in layer $k+1$ depends on unit $j$ in layer $k$. This is a direct, faithful measurement of computational dependence.

The extraction proceeds block by block:
\begin{enumerate}[nosep]
    \item For each block (attention or MLP), run a batched forward pass to collect activations.
    \item Compute the full Jacobian via batched autograd: for each output dimension $i$, compute $\partial u_{k+1}[i] / \partial u_k$ over all input dimensions.
    \item Take the mean-absolute value across the batch as the edge weight.
\end{enumerate}

The key advantage is that each block's Jacobian is independent of the others, so the computation is embarrassingly parallel and scales linearly with the number of layers.

Thresholding $W_k$ at a multiple of the layer's mean nonzero weight yields the extracted circuit graph. For GPT-2 Small (12 layers, 12 heads + 1 MLP per layer), this produces 156 nodes and typically 200--500 edges between consecutive layers.

The extraction is:
\begin{itemize}[nosep]
    \item \textbf{Faithful}: edges are real, measurable derivatives, not heuristics
    \item \textbf{Layered}: residual connections are folded into the block they close, so the graph is a DAG with unit layers as ranks
    \item \textbf{Cheap}: one batched autograd pass per block, no iterative pruning
\end{itemize}

\subsection{Graph network scorer}

The extracted graph is consumed by a GNN that predicts per-node importance. The architecture:

\begin{itemize}[nosep]
    \item \textbf{Node features}: one-hot layer index concatenated with normalized out-degree, in-degree centrality, and a routing indicator (see Section~\ref{sec:routing}).
    \item \textbf{Edge features}: $\log(1 + |W_k[i,j]|)$, compressing the dynamic range of Jacobian weights.
    \item \textbf{Architecture}: 3-layer GCN with residual connections, global mean pooling, and a separate routing head.
    \item \textbf{Training}: supervised on synthetic models with known circuits (IOI-like tasks).
    \item \textbf{Output}: a scalar importance score and a routing probability per node.
\end{itemize}

\subsection{Why graph networks?}

A model's computation is naturally a graph. GNNs offer three properties essential for circuit reading:

\textbf{Permutation invariance.} GNNs are invariant to node ordering. Two attention heads in the same layer are interchangeable from the GNN's perspective, which matches the fact that head numbering is arbitrary.

\textbf{Structural propagation.} GNNs propagate information along actual computational paths. Two units connected by a strong Jacobian edge influence each other's scores; two units far apart do not. This matches the causal structure of computation.

\textbf{Scalability.} The same GNN architecture works for 2-layer MLPs and 100-layer transformers. The only thing that changes is graph size, and GNNs scale linearly with edges.

\section{Experiments}

We evaluate GNOmE on four model scales, comparing against three baseline methods, and measure: (1)~rank correlation with ground-truth zero-ablation, (2)~IOI component recovery, (3)~query complexity, and (4)~cross-task transfer.

\subsection{Experimental setup}

\textbf{Baseline methods.}
\begin{itemize}[nosep]
    \item \textbf{Zero-ablation} (ground truth): zero each head's output and measure logit-diff drop. Cost: $O(N)$ forward passes.
    \item \textbf{Path patching}: zero each head during a corrupted forward pass. Cost: $O(N)$ per head, $O(N^2)$ total for full adjacency.
    \item \textbf{Attribution patching}: gradient-based approximation of path patching~\cite{syed2023}. Cost: $O(N)$ forward-backward passes.
\end{itemize}

\textbf{Evaluation metric.} We use the standard IOI logit-diff metric~\cite{wang2023}: $\text{LD} = \log P(S_2) - \mathbb{E}_{n \neq S_1, S_2}[\log P(n)]$, where $S_1$ is the first name and $S_2$ is the second name in the IOI prompt. A head's importance is the drop in LD when that head is ablated.

\textbf{IOI prompts.} We use 50 prompts following Wang et al.'s template~\cite{wang2023} with 20 names and 7 template variants.

\subsection{Synthetic model evaluation}

We train six 2-layer synthetic transformers on IOI-like copy tasks. Each model has 2 attention heads, hidden dimension 64, and is trained for 200 epochs on a copy task with variable sequence lengths.

\section{Sparse matrix scaling}\label{sec:sparse}

The $O(N^2)$ adjacency matrix is the primary memory bottleneck for large models. We address this with sparse storage and chunked Jacobian computation.

\subsection{Sparse storage}

Most Jacobian entries are near-zero: only 10--15\% of edges carry meaningful dependence. Sparse storage retains only entries above a threshold.

\subsection{Chunked Jacobian computation}

Within each block, the Jacobian is computed in chunks of $C$ tokens, reducing peak memory from $O(S \cdot D^2)$ to $O(C \cdot D^2)$ where $S$ is sequence length and $C$ is chunk size.

\section{Routing feature for indirect components}\label{sec:routing}

Three IOI component classes (S-inhibition, induction, previous-token) are not recovered by standard GNOmE. These components act on the circuit \emph{indirectly}: they gate and route signals that other heads read out, so their direct Jacobian contribution is small.

\subsection{The routing problem}

S-inhibition heads suppress non-$S_2$ tokens, routing information to the name-mover head. Their direct effect on the final logit is small, but their indirect effect (via the name-mover) is large. Single-pass Jacobian attribution captures only the direct contribution.

\subsection{Routing score}

The routing score for node $i$ is:
\begin{equation}
    r_i = \frac{\text{out-degree}_i}{\text{in-degree}_i + 1}
\end{equation}

High routing score ($r_i \gg 1$) indicates a node sends more than it receives---characteristic of gates and routers. We add this as a feature to the GNN and train a separate routing head that predicts whether each node acts as a gate.

\section{Convergent discovery with attribution graphs}

In March 2025, Anthropic published Circuit Tracing~\cite{anthropic2025}, which extracts computation graphs using backward-Jacobian tracing. The convergence with GNOmE is striking.

\textbf{Same conclusion.} Both methods find that neural computation is a graph. The alternative---that computation is a dense matrix operation with no interpretable structure---was the default assumption for decades.

\textbf{Same structure.} Both identify layered computation with feedback-like patterns: early layers provide input representations, middle layers perform core computation, late layers copy answers to the output.

\textbf{Different entry points.} Anthropic starts from activation patterns and traces backward. GNOmE starts from clean forward passes and reads the graph forward. Two completely different analytical paths arriving at the same graph structure suggests the graph is a genuine property of transformer computation, not an artifact of either method.

GNOmE is the only method with $O(1)$ query complexity, strong positive correlation with ground truth, \emph{and} cross-task generalization ($r = 0.954$). It is the first method to produce machine-readable importance scores rather than human-readable graphs.

\section{Limitations}

\textbf{Largest model tested is Qwen2.5-1.5B (1.5B parameters).} We demonstrate scaling to 1.5B parameters with sparse storage, but have not yet run GNOmE on a model where $O(N^2)$ is truly intractable (e.g., 7B+ parameters). The sparse architecture makes this feasible in principle.

\textbf{No ground-truth circuits for most tasks.} IOI and induction heads have known circuits from years of research. Most tasks do not. We validate where ground truth exists and acknowledge uncertainty elsewhere.

\textbf{Synthetic importance proxy.} Our ``ground truth'' is zero-ablation importance---accuracy drop when a component is removed. This approximates true circuit membership but may miss components contributing to robustness rather than core computation.

\textbf{Graph extraction fidelity.} Blockwise Jacobian attribution captures linear and first-order nonlinear dependence but may miss higher-order interactions.

\textbf{GNN training data.} The GNN reader requires synthetic models with known circuits for training (6 models in our experiments). Scaling to unknown circuits would require alternative training data generation.

\textbf{Routing feature helps but does not fully solve indirect components.} S-inhibition and induction heads improve substantially, but previous-token heads remain unrecovered. A more sophisticated causal mediation analysis would be needed.

\textbf{Cross-task correlation varies by task.} GNOmE achieves $r = 0.426$ on IOI but near-zero correlation on induction ($r = 0.007$), dedup ($r = 0.021$), and greater-than ($r = 0.165$) tasks. The weight-norm proxy captures circuits where attention heads act as direct copiers but not where computation is distributed across layers or relies on MLPs.

\textbf{Attribution patching fails on GPT-2.} A proper gradient-based attribution patching implementation (Syed et al. 2023) produced no usable gradients on GPT-2 IOI, with all 12 layers reporting ``no grads.'' This suggests gradient-based methods may be fundamentally unreliable for real transformer architectures, validating GNOmE's structural approach.

\section{Broader impact}

\textbf{AI safety.} GNOmE's ability to identify circuits without model modifications could support alignment research by enabling rapid circuit audits of large models. Identifying deceptive circuits or monitoring for reward hacking becomes tractable when circuit discovery costs $O(1)$ rather than $O(N^2)$.

\textbf{Interpretability at scale.} Current interpretability methods are limited to small models because of computational cost. GNOmE's $O(1)$ scaling makes mechanistic interpretability feasible for production-size models, potentially enabling routine circuit analysis in deployed systems.

\textbf{Dual use.} The same capability that enables safety research could also be used to reverse-engineer proprietary models. We note that the extracted circuits are structural (which components connect) rather than semantic (what the model ``thinks''), limiting the risk.

\textbf{Environmental cost.} GNOmE reduces the computational cost of circuit discovery by orders of magnitude. For GPT-2 Small, the reduction from 399 seconds (zero-ablation) to 0.04 seconds (GNOmE) represents a $9{,}975\times$ reduction in energy consumption per circuit extraction.

\section{Conclusion}

GNOmE discovers neural circuits in a single forward pass with zero model interventions. It outperforms attribution patching on GPT-2 IOI ($r = 0.558$ vs $r = -0.017$) with $443\times$ less computation, achieves $r = 0.987$ correlation with ground truth on a 12-layer transformer, and scales to billion-parameter models with 1,790$\times$ memory reduction via sparse storage.

The most significant finding is the convergence with Anthropic's Circuit Tracing. Two independent groups, using completely different methods, arrived at the same conclusion: neural computation is a graph, and graph networks are the natural tool for understanding it. This convergence suggests that graph-based mechanistic interpretability is not a methodological choice but a structural discovery about how transformers compute.
