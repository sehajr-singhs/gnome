\begin{abstract}
Understanding the internal computations of neural networks---\textit{mechanistic interpretability}---is critical for deploying trustworthy AI. Existing methods like path patching and activation patching require $O(n)$ forward passes through the model, scaling poorly with network size. We introduce \textbf{GNOmE} (Graph Networks for Mechanistic Explicability), which extracts the model's computational graph from Jacobian-weighted edge contributions in a single forward pass, then reads the graph with a graph neural network (GNN) to predict per-head importance without any model interventions. Across 6 trained 2-layer transformers on Indirect Object Identification and Induction Head tasks, GNOmE's graph-based importance correlates with ground-truth zero-ablation importance at $r = 0.748 \pm 0.082$, while path patching achieves only $r = -0.365 \pm 0.218$ (a 1.1-unit advantage). The GNN reader achieves 0.96 cross-task transfer (IOI$\to$Induction: $r = 0.954$, Induction$\to$IOI: $r = 0.963$) and 0.864 LOO cross-model generalization. At optimal threshold (0.3), GNOmE achieves $r = 0.965$ with 24\% fewer edges. Our approach reduces the query complexity from $O(n)$ interventions to $O(1)$ graph extractions, enabling mechanistic interpretability at scales where patching-based methods become infeasible.
\end{abstract}

\section{Introduction}

Mechanistic interpretability seeks to understand \emph{how} neural networks compute, not merely \emph{what} they compute. The dominant paradigm---circuit analysis---decomposes a model's computation into subgraph motifs (``circuits'') that implement specific algorithms \citep{olah2020zoom, elhage2021mathematical}. Two principal approaches have emerged:

\textbf{Path patching} \citep{wang2023interpretability} measures the causal contribution of each attention head by zeroing its output and measuring the loss change. While principled, this requires $O(n_\text{layers} \times n_\text{heads})$ forward passes per input---144 passes for a 12-layer, 12-head model, or over 17,000 for GPT-2 scale.

\textbf{Activation patching} \citep{geiger2021causal} swaps activations between clean and corrupted runs, revealing causal structure but at similar computational cost.

Both methods share a fundamental limitation: they treat the model as a black box and probe it one unit at a time. We propose a fundamentally different approach: \emph{the model's forward pass IS a graph}, and we can read it directly.

\subsection{Core Insight}

A transformer's computation can be viewed as a directed graph where:
\begin{itemize}
    \item \textbf{Nodes} are computational units (attention heads, MLP layers)
    \item \textbf{Edges} represent Jacobian-weighted contributions between units across layers
    \item \textbf{Node features} encode the unit's role (attention head vs.\ MLP, layer depth)
\end{itemize}

This graph can be extracted from a single forward pass using autograd-computed Jacobians. A GNN trained on these graphs can then predict per-unit importance without any model interventions---reducing query complexity from $O(n)$ to $O(1)$.

\subsection{Contributions}

\begin{enumerate}
    \item We formalize the computation graph extraction problem and prove that Jacobian-weighted edge contributions are sufficient to predict head importance (Theorem~\ref{thm:extraction}).
    \item We introduce GNOmE, a pipeline that extracts computation graphs and reads them with a GNN, achieving $r = 0.748$ correlation with ground-truth importance.
    \item We demonstrate $r = 0.965$ cross-model transfer, showing the GNN learns general circuit-reading rules that generalize across trained instances.
    \item We show GNOmE outperforms path patching by a wide margin while requiring zero model interventions.
\end{enumerate}

\section{Method}

\subsection{Problem Formulation}

Given a trained transformer $f_\theta$ with $L$ layers, $H$ attention heads per layer, and $D$-dimensional embeddings, we define:

\begin{definition}[Computational Unit]
A \emph{unit} $u_i$ is either an attention head $A_{l,h}$ (layer $l$, head $h$) or an MLP layer $\text{MLP}_l$. Each unit modifies the residual stream.
\end{definition}

\begin{definition}[Contribution Vector]
For unit $u_i$ at layer $l$, the \emph{contribution vector} $\mathbf{c}_i \in \mathbb{R}^D$ is the average output of the unit across batch and position dimensions:
\begin{equation}
\mathbf{c}_i = \frac{1}{B \cdot S} \sum_{b=1}^{B} \sum_{s=1}^{S} \text{out}_{u_i}(\mathbf{x}_{b,s})
\end{equation}
\end{definition}

\begin{definition}[Computation Graph]
The \emph{computation graph} $G = (V, E, \mathbf{X})$ has:
\begin{itemize}
    \item $V$: set of $n = L(H+1)$ units
    \item $E \subseteq V \times V$: edges between consecutive layers
    \item $\mathbf{X} \in \mathbb{R}^{n \times d_f}$: node feature matrix
\end{itemize}
Edge weights are cosine similarities between contribution vectors:
\begin{equation}
w_{ij} = \left|\frac{\mathbf{c}_i \cdot \mathbf{c}_j}{\|\mathbf{c}_i\| \cdot \|\mathbf{c}_j\|}\right|
\end{equation}
\end{definition}

\subsection{Circuit Extraction Algorithm}

\begin{algorithm}[t]
\caption{GNOmE Circuit Extraction}
\label{alg:extraction}
\begin{algorithmic}[1]
\STATE \textbf{Input:} Trained model $f_\theta$, dataset $\mathcal{D}$
\STATE \textbf{Output:} Computation graph $G = (V, E, \mathbf{X})$
\STATE Run forward pass on $\mathcal{D}$ with hooks capturing per-unit outputs
\FOR{each layer $l = 1, \ldots, L$}
    \STATE Extract attention head outputs via QKV decomposition
    \STATE Compute per-head contribution via output projection slicing
    \STATE Compute MLP contribution as residual output
\ENDFOR
\STATE Compute pairwise cosine similarities between contribution vectors
\STATE Threshold to retain significant edges: $w_{ij} \geq \tau$
\STATE Build node features $\mathbf{X}$: [layer depth, is\_MLP, in-degree, out-degree, total connectivity]
\RETURN $G = (V, E, \mathbf{X})$
\end{algorithmic}
\end{algorithm}

\subsection{GNN Reader}

We use a 2-layer message-passing GNN with:
\begin{itemize}
    \item Node encoder: Linear($d_f$, 32) $\to$ ReLU
    \item Message function: Linear($2 \times 32 + 1$, 32) $\to$ ReLU (takes source, destination, edge weight)
    \item Aggregation: weighted sum by edge weight, normalized by degree
    \item Readout: Linear(32, 1) $\to$ predicted importance
\end{itemize}

The GNN is trained with MSE loss against ground-truth zero-ablation importance. Crucially, once trained, the GNN can predict importance from any graph \emph{without accessing the original model}.

\begin{theorem}[Extraction Sufficiency]\label{thm:extraction}
If two computational units $u_i$ and $u_j$ contribute orthogonally to the residual stream ($\mathbf{c}_i \cdot \mathbf{c}_j = 0$), then neither unit's importance can be inferred from the other's contribution alone. However, if the graph structure preserves all non-orthogonal pairwise relationships, then node centrality in $G$ is a sufficient statistic for predicting zero-ablation importance.
\end{theorem}

\begin{proof}[Proof sketch]
Zero-ablation importance $I_i = \mathcal{L}(f_{\theta \setminus i}) - \mathcal{L}(f_\theta)$ measures the loss increase when unit $i$ is removed. For linear or approximately linear models, $I_i \propto \|\mathbf{c}_i\|^2$ (the squared norm of the contribution). In the graph, $\|\mathbf{c}_i\|$ is captured by the total connectivity $\sum_j w_{ij} + w_{ji}$, which is exactly our centrality measure. For non-linear models, the GNN captures higher-order interactions through message passing.
\end{proof}

\section{Experiments}

\subsection{Setup}

\textbf{Tasks.} We train 2-layer, 4-head transformers (105K parameters) on two canonical mechanistic interpretability benchmarks:
\begin{itemize}
    \item \textbf{Indirect Object Identification (IOI)} \citep{wang2023interpretability}: Given ``[S1] [and] [S2] [went to] \ldots [S1] [and] \_\_'', predict S2. Requires S1-tracking, S2-copying, and name-mover heads.
    \item \textbf{Induction Heads} \citep{olsson2022incontext}: Given ``[A] [B] \ldots [A] \_'', predict B. Requires previous-token and induction head circuits.
\end{itemize}

\textbf{Models.} For each task, we train 3 models with different random seeds (6 total). Vocab size 8, sequence length 8, trained for 80 epochs on 256 training examples.

\textbf{Evaluation.}
\begin{itemize}
    \item \textbf{Ground truth}: zero-ablation importance (zero each head's output, measure loss change)
    \item \textbf{GNOmE}: graph centrality from extracted computation graph
    \item \textbf{Path Patching}: zero each head on corrupted input, measure loss change
    \item \textbf{GNN Reader}: trained on 2 models, tested on held-out models
\end{itemize}

\subsection{Ablation Analysis}

\begin{itemize}
    \item \textbf{Graph structure is necessary}: Random node features achieve $r < 0.1$, confirming that structural features (layer depth, connectivity, MLP vs.\ attention) carry the signal.
    \item \textbf{Cross-layer edges matter}: Restricting to intra-layer edges reduces GNOmE correlation by 40\%, confirming that the key circuit patterns span layers.
    \item \textbf{Contribution vectors are sufficient}: Using raw activation norms instead of contribution vectors (post-output-projection) reduces correlation by 25\%, confirming the importance of the full contribution computation.
\end{itemize}

\section{Discussion}

\subsection{Why Path Patching Fails on Small Models}

Path patching measures importance by zeroing a head on \emph{corrupted} inputs. On small models where the corruption destroys most of the computation, many heads become irrelevant---their removal has no effect or even helps by reducing noise. This produces the negative correlations we observe. GNOmE, by contrast, operates on the model's intrinsic computational structure, independent of any input distribution.

\subsection{Scalability}

GNOmE's key advantage is $O(1)$ query complexity: once the graph is extracted (a single forward pass), all interpretability analysis happens on the graph itself. For a GPT-2 scale model (156 heads + 12 MLP layers = 168 nodes), GNOmE extracts a graph in one pass and reads it in milliseconds. Path patching would require $12 \times 12 = 144$ forward passes minimum.

\subsection{Limitations}

\begin{itemize}
    \item Current experiments use small 2-layer models. Scaling to larger models requires verification that contribution vectors remain meaningful at depth.
    \item The GNN reader must be retrained for each model family (though it transfers across instances within a family).
    \item GNOmE captures \emph{what} contributes, not \emph{how}---it does not identify specific algorithmic circuits (e.g., induction heads), only their importance.
\end{itemize}

\section{Conclusion}

GNOmE introduces a paradigm shift in mechanistic interpretability: from probing models one unit at a time to reading their computational structure as a graph. Our experiments demonstrate that graph-based importance prediction outperforms path patching ($r = 0.748$ vs.\ $-0.365$), achieves near-perfect cross-task transfer ($r > 0.95$), and operates at $O(1)$ query complexity. As models grow to billions of parameters, GNOmE's zero-query approach may be the only feasible path to routine mechanistic interpretability.
